# Книжный Клуб

Веб-приложение для женского книжного клуба. Минималистичный тёплый дизайн, оптимизировано для мобильных устройств и упаковки в Capacitor (Android/iOS).

## Стек

- **React 19** + TypeScript
- **Vite** — сборка
- **Tailwind CSS v4** + **shadcn/ui** — стили и UI
- **React Router v7** — маршрутизация
- **Lucide React** — иконки

## Разделы

- **Главная** — лента постов, книга месяца, ближайшее событие, дни рождения
- **Книги** — каталог, книга месяца, архив, отзывы
- **Голосования** — выбор книги, даты встречи
- **Мероприятия** — встречи, квартальные события, RSVP
- **Болталка** — чат с тредами
- **Конкурсы** — викторины, подарки, дни рождения

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Деплой

Готов к деплою на Vercel, Netlify или любой статический хостинг. SPA fallback настроен.
